# Asynchronous processing worker

Implement in TypeScript on Node.js, matching the API. Own S3 event processing, metadata validation, vision-provider adapter, structured-output validation, observation/detection persistence, enrichment, issue association, and scoring orchestration.

Share runtime-validated contracts with the API. Processing must be idempotent and retry-safe. Persist model/schema/formula versions and explicit status/error details; never convert inference failure or invalid JSON into a successful detection.
