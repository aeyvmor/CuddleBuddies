# Team handoff memory

Use this folder for brief cross-session working memory: current state, owners, blockers, and next actions. Keep requirements and architecture decisions in `.kiro/` and `docs/` as the durable source of truth.

At the end of a work session, update `current-state.md` with what changed, checks run, the next concrete step, and any unresolved decision. Avoid credentials, personal data, and long copied transcripts.
