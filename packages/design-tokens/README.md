# Shared design tokens

Keep named, semantic design values here so the UI designer can change visual direction without changing feature logic.

Define shared concepts (for example color roles, spacing, type scale, radii, and elevation) in a framework-neutral source where practical. The web app can map them to CSS custom properties; React Native can map them to typed style values. Do not force identical platform styling where native conventions differ.

Coordinate token names and examples with the UI designer before implementing a full component library.
